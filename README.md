# Rodando Seguro Web

Landing page estática para el taller mecánico de bicicletas de Don Carlos.

## Estructura

- `index.html`: Estructura principal de la página
- `css/styles.css`: Estilos y diseño responsivo
- `js/main.js`: Interacciones básicas
- `assets/img/`: Fotografías del local, logo e íconos
- `assets/docs/`: Catálogo de precios PDF
